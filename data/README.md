# Data Setup

This repo expects data in the following structure:

```
data/
├── raw/
│   └── da-input/
│       ├── cannon-beach-da.csv      # 306 measurements
│       ├── clatsop-beach-da.csv     # 1087 measurements
│       ├── coos-bay-da.csv          # 335 measurements
│       ├── copalis-da.csv           # 933 measurements
│       ├── gold-beach-da.csv        # 717 measurements
│       ├── kalaloch-da.csv          # 710 measurements
│       ├── long-beach-da.csv        # 774 measurements
│       ├── newport-da.csv           # 708 measurements
│       ├── quinault-da.csv          # 602 measurements
│       └── twin-harbors-da.csv      # 760 measurements
└── processed/
    └── final_output.parquet         # Weekly env features
```

## Raw DA Measurements

Source: Lab measurements from WA DOH, OR DFW, Olympic Region HAB Partnership.

**Format** (varies by file):
- Oregon sites: `CollectDate`, `Domoic Result`
- Washington sites: `Harvest Month`, `Harvest Date`, `Harvest Year`, `Domoic Acid`

**Date range**: 2002–2023 (varies by site)

**Total measurements**: ~6,600 across all sites

## Processed Environmental Data

Source: Generated by `dataset-creation.py` in the original DATect repo.

**Contents** (`final_output.parquet`):
- Weekly rows (every Monday) from 2003-01-06 to 2023-12-25
- 10 sites × ~1095 weeks = ~10,950 rows
- 17 columns: `date`, `site`, `lat`, `lon`, `oni`, `pdo`, `discharge`, `da`, `pn`, `beuti`, `chla-anom`, `modis-chla`, `modis-flr`, `modis-k490`, `modis-par`, `modis-sst`, `sst-anom`

**Feature descriptions**:
| Column | Description | Source |
|--------|-------------|--------|
| `modis-chla` | Chlorophyll-a concentration | MODIS satellite |
| `modis-sst` | Sea surface temperature | MODIS satellite |
| `modis-par` | Photosynthetically active radiation | MODIS satellite |
| `modis-flr` | Fluorescence line height | MODIS satellite |
| `modis-k490` | Diffuse attenuation coefficient | MODIS satellite |
| `chla-anom` | Chlorophyll anomaly | Derived |
| `sst-anom` | SST anomaly | Derived |
| `beuti` | Biologically Effective Upwelling Transport Index | NOAA |
| `pdo` | Pacific Decadal Oscillation | NOAA |
| `oni` | Oceanic Niño Index | NOAA |
| `discharge` | Columbia River streamflow | USGS |
| `da` | Interpolated DA (used in original pipeline) | Derived |
| `pn` | Pseudo-nitzschia cell counts | Lab measurements |

## Setup Instructions

Copy or symlink from the original DATect repo:

```bash
# From this repo's root directory:
ln -s /path/to/DATect-Forecasting-Domoic-Acid/data/raw/da-input data/raw/da-input
ln -s /path/to/DATect-Forecasting-Domoic-Acid/data/processed/final_output.parquet data/processed/final_output.parquet
```

Or copy directly:

```bash
cp -r /path/to/DATect-Forecasting-Domoic-Acid/data/raw/da-input data/raw/
cp /path/to/DATect-Forecasting-Domoic-Acid/data/processed/final_output.parquet data/processed/
```
